# Идеи и планы (backlog)

Здесь собраны идеи, которые нужно реализовать. Порядок отражает приоритет; отметки
обновляются по мере работы. Основной план по этапам — в [ROADMAP.md](ROADMAP.md).

## Сделано в этой итерации

- [x] Пасхалка в About: логотип — интерактивная «вода» (`UI/WaterLogo.cs`), клик и
      перетаскивание дают круги и искажение картинки.
- [x] Музыка в About: включается при открытии, выключается при закрытии, кнопка вкл/выкл.
- [x] Выбор музыки («Another music...»): встроенные треки, импорт MIDI и TXT, экспорт в MIDI.
- [x] Свой синтезатор (`Music/ChiptuneSynth.cs`) — без DirectX и сторонних библиотек,
      работает на XP.
- [x] MIDI → TXT → MIDI конвертер (`Music/MidiReader.cs`, `MidiWriter.cs`, `MidiTextFormat.cs`).
- [x] Рекурсивная обработка папок (`File → Open Folder`, флаг «Recursive folders»).
- [x] Ленивое дерево: `References` раскрываются по клику, внутрь можно «зайти» (assembly →
      module → namespace → type → members), без подвисаний.
- [x] Кликабельные Base Types / интерфейсы.
- [x] Замена native-бинарников на managed-аналоги: ILDasm, ILAsm, дизассемблер x86,
      Fusion/GAC-резолвер.
- [x] Выбор диалекта вывода: C# 1.0…9.0, SharpDevelop, VB (`OutputDialect`).

## Совместимость и историческая ценность

- [ ] Декомпиляция сборок любых версий .NET (1.0 … 9.0) при запуске на XP: нужен свой
      metadata reader, не зависящий от установленного CLR (Cecil читает файл, но
      резолв зависимостей и `mscorlib` для новых TFM требует отдельной логики).
- [ ] Профили «целевой рантайм»: `net10`…`net48`, `netcoreapp`, `net5+` — влиять на имена
      типов (`System.Private.CoreLib`), набор ключевых слов и генерируемый код.
- [ ] Профили «целевой компилятор»: VS 2002/2003/2005/2008/2010/2012/2013/2015/2017/2019/2022,
      SharpDevelop 1.x–5.x, MonoDevelop, Roslyn — с проверкой, что сгенерированный код
      компилируется этим компилятором (сейчас диалект влияет на заголовок и доступные
      конструкции, полная матрица синтаксиса — TODO).
- [ ] Проверка синтаксиса через `csc.exe` выбранной версии, если он найден на машине.
- [ ] Набор тестовых сборок, собранных старыми компиляторами (для регрессий).
- [ ] Поддержка .NET Framework 1.0/1.1 сборок (метаданные v1.0, mscorlib 1.0.3300).
