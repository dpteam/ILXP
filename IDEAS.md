# Идеи и планы (backlog)

Здесь собраны идеи, которые нужно реализовать. Порядок отражает приоритет: сначала
дешёвые и полезные вещи, потом крупные. Основной план по этапам — в
[ROADMAP.md](ROADMAP.md).

## Сделано

### About / музыка / вода
- [x] Логотип — интерактивная «вода» (`UI/WaterLogo.cs`): крупные видимые бульки, клик и
      перетаскивание, фоновые капли каждые ~1.7 с, голубая рефракция и блики по лапласиану.
- [x] Музыка включается при открытии About и выключается при закрытии, кнопка вкл/выкл.
- [x] «Another music...»: встроенные треки, импорт MIDI, импорт TXT, экспорт в MIDI.
- [x] **Полноценный GM-движок** (`Music/InstrumentMap.cs`, `Music/Synthesizer.cs`):
      все 128 программ (пиано, хроматика, орган, гитара, бас, струнные, ансамбли, духовые,
      язычковые, флейты, synth lead/pad/FX, этника, перкуссия, эффекты) + вся карта ударных
      (35–81). У каждого инструмента свой набор осцилляторов, ADSR, фильтр, вибрато,
      детюн, PWM.
- [x] Синтез: pulse/triangle/saw/sine/noise, резонансный state-variable low-pass с
      огибающей, vibrato, detune, PWM, громкость/экспрессия/панорама по каналам,
      sustain-педаль, стерео, мягкий лимитер, таблицы волн (быстро).
- [x] Рендер в WAV потоком + кэш по хешу содержимого (второй запуск трека мгновенный).
- [x] `--music` конвертирует `.mid` ↔ текст и рендерит `.wav`.

### Сборка / нативные библиотеки

- [x] `native/` больше не копируется в билд; managed-замены полностью покрывают функции:

- [x] `--headless`: скриптовая оболочка (`open`, `list`, `type`, `method`, `accuracy`,

- [x] GitHub Actions: сборка AnyCPU/x86/x64, тесты, smoke-тест, отчёт о точности,

- [x] Исправлены грабли CI: `.slnx` объявляет конфигурации (`Debug`/`Release` ×

- [ ] CI: кэш NuGet/`obj`, матрица по `Configuration`, публикация релиза по тегу

- [ ] CI: отдельный job «deobfuscation quality» — обфусцировать ILXP.exe своим

- [ ] **Поиск по IL** (regex по тексту инструкций), а не только по именам.

### Уровень 2: полезная аналитика (3–5 дней)

- [ ] **Перенос настроек из ILSpy/dnSpy**: при переносе фич тащить и их настройки
      (ILSpy: `%APPDATA%\ICSharpCode\ILSpy.xml`; dnSpy: `%APPDATA%\dnSpy\*.xml`),
      маппить совпадающие ключи в `AppSettings`, неизвестные складывать в раздел
      «Imported (read-only)». Плюс импорт/экспорт `.ilxp-settings` для переноса между
      машинами.
- [ ] **Больше своих настроек**: тема (светлая/тёмная), шрифт редактора и размер,
      показывать IL-комментарии, автораскрытие дерева при загрузке, лимит истории
      навигации, формат логов, «спрашивать перед очисткой».
- [ ] **Health report сборки**: энтропия секций, подозрительные атрибуты, отсутствующие
      зависимости, признаки обфускации, наличие PDB, целевой рантайм — единый отчёт.
- [ ] **Fingerprint обфускатора**: определять протектор по маркерам (имена типов, атрибуты,
      строки, энтропия) и предлагать подходящие пассы. Визуально: «вероятно ConfuserEx 1.6».
- [ ] **Call graph explorer** по всем открытым сборкам: кто кого вызывает, недостижимый код
      после чистки, самые «горячие» методы по числу вызовов.
- [ ] **Diff двух версий сборки**: добавленные/удалённые/изменённые типы и методы по хешу IL.
      Для археологии «что поменялось между 1.2 и 1.3».
- [ ] **Timeline версий**: найти в папке одноимённые сборки разных версий и показать рядом.
- [ ] **Fixpoint-тест**: decompile → ilasm → decompile → сравнить IL, показывать «потери»
      как список конструкций (честная метрика качества декомпилятора).

### Уровень 3: деобфускация (неделя+)

- [ ] Портировать оставшиеся пассы Unscrambler: `ConvertToIntReplace`, `DoubleParseReplace`,
      `CalliReplace`, `HideCallsRemover`, `LocalsToFieldRemover`, `InterfaceLoopRemover`.
- [ ] **Time-travel пайплайна**: для одного метода хранить IL до/после каждого пасса и
      показывать слайдером. Очень помогает писать новые деобфускаторы.
- [ ] **База восстановленных имён**: один раз переименовал `a.b.c` → сохраняется в
      `%APPDATA%\ILXP\symbols\<sha256>.json` и применяется при следующей декомпиляции
      этой же сборки. Data-hoarder-friendly.
- [ ] dnlib как `src/dnlib`, затем `de4dot.blocks` и `de4dot.code.renamer`.
- [ ] Плагины de4dot по приоритету: Confuser/ConfuserEx, .NET Reactor, Eazfuscator,
      SmartAssembly, Babel, CryptoObfuscator, Dotfuscator, Xenocode.
- [ ] **Свой набор тестовых обфускаторов** (расширять `TestObfuscator`): control-flow
      flattening, string encryption, proxy calls, анти-дамп, анти-тампер. Тогда качество
      деобфускации можно мерить численно, без скачивания протекторов.

- [ ] Полная матрица «целевой рантайм × целевой компилятор» с проверкой синтаксиса через

- [ ] Декомпиляция сборок .NET 1.0/1.1 (метаданные v1.0, mscorlib 1.0.3300).
- [ ] Свой metadata reader для запуска на XP против сборок .NET 5+ (Cecil читает файл, но

- [ ] Экспорт проекта (`.csproj`/`.sln`) с выбранным TargetFramework и языком.
- [ ] Восстановление `async`/`await`, лямбд и итераторов из state machine-классов.
- [ ] Восстановление имён из PDB и из атрибутов.

### Уровень 5: сохранение (data hoarding)

- [ ] **Preservation bundle**: оригинальные байты + IL + ресурсы + метаданные JSON +
      скриншоты + SHA-256 в один `.zip` с манифестом. Ровно под цель проекта.
- [ ] **Каталог коллекции**: просканировать диск/папку, построить индекс всех .NET-сборок
      (имя, версия, TFM, обфускация, дата), хранить в SQLite/JSON, искать по нему.
- [ ] **Проверка воспроизводимости**: для каждой сборки хранить, что удалось восстановить,
      и «степень сохранности» (0–100).
- [ ] Импорт из дампов памяти: сканирование `MZ`/PE (карвинг уже есть) + восстановление по
      «сырым» метаданным без PE-заголовка.

### Уровень 6: интересные «киллер-фичи»

- [ ] **Аннотации поверх кода**: заметки, привязанные к оффсету IL, сохраняются в проекте.
- [ ] **Сравнение «до/после деобфускации»** бок о бок с подсветкой изменённых инструкций.
- [ ] **Генератор тестовых сборок**: собрать сборку с заданными конструкциями (generics,
      async, события, P/Invoke) и прогнать по ней весь пайплайн — регрессия декомпилятора.
- [ ] **Карта зависимостей** (граф сборок с подсветкой отсутствующих).
- [ ] **BAML/XAML-просмотрщик** для WPF-сборок.
- [ ] **Встроенный hex-вьюер** с подсветкой структур PE/метаданных.
